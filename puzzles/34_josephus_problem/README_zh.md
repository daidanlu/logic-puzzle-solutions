# 约瑟夫环的二进制移位表示

## The Josephus Problem

约瑟夫问题是一个具有循环递归结构的经典离散数学模型。对于步长为 2 的情形，它可以被化简为一个简单的二进制位移公式，从而避免显式模拟整个循环链表。

## 系统设定与拓扑环境

存在 $N$ 个智能体，编号为 $1$ 到 $N$，它们按编号顺序构成一个环。

系统从编号 $1$ 开始执行淘汰过程：
$1$ 淘汰 $2$，$3$ 淘汰 $4$，$5$ 淘汰 $6$，依此类推。淘汰过程沿环继续进行，跳过已被淘汰的节点，直到只剩下最后一个存活节点。

目标是求最后的幸存者编号，记为：

$$W(N)$$

## 直观方法与计算代价

最直接的方法是构建一个循环链表，并按步长 $2$ 进行模拟。该方法需要依次删除节点，因此时间复杂度为：

$$O(N)$$

当 $N$ 很大时，线性模拟会变得低效。因此，我们希望找到一个不依赖链表模拟的闭式表达式。

---

# 递归结构与位运算表示证明

该问题的关键在于寻找淘汰过程中的结构性不变量。

## 第一步：定义不变量状态：$N = 2^m$

先考虑特殊情形：

$$N = 2^m$$

也就是说，初始人数恰好是 $2$ 的整数次幂。

在第一轮淘汰中，所有偶数编号都会被淘汰：

$$2,4,6,\dots,2^m$$

剩下的节点为：

$$1,3,5,\dots,2^m-1$$

此时剩余节点数为：

$$2^{m-1}$$

并且下一次执行淘汰动作的起点重新回到编号 $1$。

因此，问题在结构上缩小为同类型问题：剩余人数从 $2^m$ 变为 $2^{m-1}$，而起点仍然是编号 $1$。

不断递归下去可知，当初始人数为 $2$ 的整数次幂时，最终幸存者必然是：

$$W(2^m)=1$$

---

## 第二步：对任意 $N$ 进行代数分解

对于任意正整数 $N$，令 $2^m$ 是不超过 $N$ 的最大 $2$ 的次幂。于是可以唯一写成：

$$N = 2^m + L$$

其中：

$$0 \leq L < 2^m$$

这里 $L$ 表示 $N$ 超出最大 $2$ 次幂部分的余量。

---

## 第三步：先淘汰 $L$ 个节点，使系统进入 $2^m$ 状态

从编号 $1$ 开始，前 $L$ 次淘汰会依次淘汰：

$$2,4,6,\dots,2L$$

因此，执行完 $L$ 次淘汰后，系统中的存活节点数变为：

$$N-L = 2^m$$

也就是说，剩余人数恰好变成了一个 $2$ 的整数次幂。

与此同时，下一次执行淘汰动作的节点是：

$$2L+1$$

因此，在剩余的 $2^m$ 个节点中，编号 $2L+1$ 成为了新的起点。

---

## 第四步：应用 $2^m$ 情形的结论

根据第一步，当剩余人数为 $2^m$ 时，如果从某个节点开始执行同样的淘汰过程，那么这个起点节点在重新编号后的系统中对应位置 $1$，因此它最终会成为幸存者。

此时新的起点是原始编号：

$$2L+1$$

所以对于任意 $N = 2^m + L$，最终幸存者为：

$$W(N)=2L+1$$

其中：

$$L = N - 2^m$$

因此也可以写成：

$$W(N)=2(N-2^m)+1$$

---

## 第五步：二进制表示与循环左移

将 $N$ 写成二进制。由于：

$$N = 2^m + L$$

其中 $2^m$ 是最高位的 $1$，而 $L$ 对应其后的低位部分。

因此 $N$ 的二进制形式可以写成：

$$N = (1b_{m-1}b_{m-2}\dots b_0)_2$$

其中：

$$L = (b_{m-1}b_{m-2}\dots b_0)_2$$

由闭式公式：

$$W(N)=2L+1$$

可知：

1. 去掉 $N$ 二进制表示中的最高位 $1$，得到 $L$；
2. 将 $L$ 左移一位，得到 $2L$；
3. 在最低位补 $1$，得到 $2L+1$。

也就是说，$W(N)$ 的二进制表示等价于：

$$(b_{m-1}b_{m-2}\dots b_0 1)_2$$

这正是把 $N$ 的最高位 $1$ 移到最低位之后得到的结果。

因此，在固定机器字长或固定有效位宽下，该公式可以理解为对 $N$ 的有效二进制表示执行一次循环左移：

$$(1b_{m-1}b_{m-2}\dots b_0)_2 \longmapsto (b_{m-1}b_{m-2}\dots b_0 1)_2$$

需要注意的是：如果 $N$ 是任意精度大整数，那么从输入长度角度看，读取和移动全部二进制位仍然需要与位数成正比的时间；但相对于按人数 $N$ 进行链表模拟，该方法已经将问题降为对二进制表示长度的计算。

---

## 实例

令：

$$N=41$$

则：

$$41 = 32 + 9 = 2^5 + 9$$

所以：

$$L=9$$

代入公式：

$$W(41)=2L+1=2\cdot 9+1=19$$

从二进制角度看：

$$41=(101001)_2$$

将最高位 $1$ 移到最低位：

$$101001 \longmapsto 010011$$

去掉前导零后得到：

$$10011_2 = 19$$

因此：

$$W(41)=19$$

---

## 结论

对于步长为 $2$、从编号 $1$ 开始的约瑟夫环问题，若：

$$N = 2^m + L,\qquad 0 \leq L < 2^m$$

则最后幸存者为：

$$\boxed{W(N)=2L+1}$$

等价地，在二进制表示中，最终幸存者可以通过将 $N$ 的最高位 $1$ 移到最低位得到。这说明该递归淘汰过程可以被化简为一个简单的二进制位移结构，从而避免显式的循环链表模拟。
